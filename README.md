# pairwise-level-streaming

跨过峡谷边界，下一块地形已经显示，碰撞却还是空气，走两步又突然被弹回原地：关卡流送按包围盒距离触发，斜向跨越时相邻格没预加载；地形网格和碰撞体分两条异步链路，渲染先到、物理后到；HLOD 切换时父节点和子节点同时可见，接缝出现双份几何；世界原点重定位后流送坐标没换算，远处格子偏移；导航网格随地形流送重建，角色寻路路径中途失效；音频区域和灯光探针按场景加载，过边界时整片静音；内存预算按格子数，贴图尺寸不同的格子爆内存；卸载只查引用计数，跨格传送门仍指向旧格；流送优先级只看距离，任务目标所在格最后加载；保存时只存当前格，回到旧区域状态丢失；多玩家在不同格，服务器流送以主机位置为准；异步加载失败没有重试，格子永久空洞；流送线程和主线程共享实体表，加载完成时实体被覆盖。gameplay/level_streaming.py 是核心，tests/test_level_streaming.py 15个红。要修的是：邻格预载；物理同步；HLOD 接缝；原点换算；导航重建；音频灯光；字节预算；跨格引用；任务优先；区域存档；多人位置；失败重试；实体表隔离。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
